# Student Management API
Student Management API is a simple backend project made using Node.js and Express.js.
This API is used to manage basic student information like student name and course. 
It supports the main CRUD operations: Create, Read, Update and Delete.

# Features
- View all students
- Add a new student
- Update student information
- Delete a student
- Basic input validation
- JSON response for API requests

# Technologies Used
- Node.js
- Express.js
- JavaScript
- Thunder Client
